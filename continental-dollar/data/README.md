# Data

`published/` — the citable files. Every CSV carries a comment header giving the source,
table and page numbers, so any figure can be traced to the printed original without
consulting the top-level README.

`working/` — the same figures with terse column names (`ma_scale`, `va_merch`, …), used by
the scripts in `analysis/`. Identical values; different column labels.

Units throughout are **Continental dollars required to purchase one specie dollar**, unless
a header says otherwise. Higher values mean greater depreciation.
